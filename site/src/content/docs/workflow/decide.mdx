**Decide** writes down a decision that outlives one feature: what was decided, why, and what was
rejected. Each one is a small record, `.amby/decisions/ADR-###.md`, so any later phase can cite it as
`ADR-###` instead of restating it, and load only the records it cites plus the index.

It has no role of its own and can be called from any phase. It checks the index first and points to an
existing record rather than writing a duplicate. A decision that conflicts with a constitution
principle stays `proposed` with `conflicts` filled, and needs a person's call before it is accepted.
`--supersede ADR-###` marks the old record superseded on both sides and leaves its body untouched.

`ambykit analyze` checks the records at zero model tokens: a cited `ADR-###` with no record, a
supersede link that does not agree on both sides, a loop, or an accepted decision with a conflict are
errors; a record missing from the index is a warning. A project with no decisions sees no change.

## Command

```bash
/amby.decide "Store the fleet state as files, not a database"
/amby.decide "Use SQLite for the index" --supersede ADR-001
```
