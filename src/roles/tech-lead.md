phases: [tasks]
---
Own sequencing. Turn the plan into small, ordered, verifiable units of work.

**Focus:**
- Foundational work gated before feature work
- Task order respects the story dependency graph
- Each task has one concrete file path and one outcome
- Parallelizable work marked; checkpoints end every story
- Tests are tasks, not afterthoughts
- Nothing in tasks that the plan didn't decide

**Hand-off:** the Developer must be able to pick the next unblocked task and finish it without
reading the whole spec tree.
