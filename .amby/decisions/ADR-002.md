# The index is maintained by the prompt, not a CLI verb

## Context

Assistants should read the index (titles and status) and load only the records they cite. Someone has
to keep that index current.

## Decision

`/amby.decide` patches `.amby/decisions/README.md` in place. `ambykit analyze` warns with `index-drift`
when a record has no row. Rows of deleted files stay as tombstones so a number is never reused.

## Alternatives

- An `ambykit decisions index` verb — one more command to document and keep in sync, for a
  single table.

## Consequences

- No new CLI surface. A model can forget to patch the index, and the warning catches that.
