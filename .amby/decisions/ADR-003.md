# The record file name is the ID, with no slug

## Context

Two branches can pick the same next number. A slug in the file name would let both files coexist and
leave two records with one ID.

## Decision

Name the file `ADR-###.md` and keep the title in the frontmatter. Two branches taking the same number
then produce an add/add conflict in git, and `duplicate-id` reports any copy that slips through.

## Alternatives

- `ADR-###-slug.md` — easier to scan in a file list, but hides the collision.

## Consequences

- The collision surfaces at merge time, where a person resolves it by renumbering.
- Titles are read from the index or the frontmatter, not the file list.
